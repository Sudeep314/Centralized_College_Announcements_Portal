# CampusNotice — Centralized College Announcements Portal

CampusNotice is a full-stack Skill Lab project designed to centralize scattered college announcements into one searchable, accessible portal.

- **Backend API:** Built with Node.js, Express.js, MongoDB (Mongoose), express-validator, and JWT authentication. Located in [`backend/`](file:///c:/Users/Vicky/OneDrive/Desktop/CCA/backend/README.md).
- **Frontend Client:** In development using standard HTML5, CSS3, and vanilla JavaScript.

---

## 🚀 Getting Started with the Backend

1. Open your terminal in the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up `.env`:
   ```bash
   # Windows PowerShell:
   Copy-Item .env.example .env
   ```
4. Seed sample announcements:
   ```bash
   npm run seed
   ```
5. Start development server:
   ```bash
   npm run dev
   ```
6. Run automated API tests:
   ```bash
   npm run test:api
   ```

For full documentation, request contracts, and Postman testing, refer to the [Backend Documentation](file:///c:/Users/Vicky/OneDrive/Desktop/CCA/backend/README.md).
